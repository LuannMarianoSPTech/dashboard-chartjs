# dashboard-chartjs

Dashboard desenvolvida utilizando **HTML, CSS, JavaScript e Chart.js** para visualizar dados de temperatura e umidade.

## 📊 Gráficos

A dashboard possui dois gráficos:

* **Gráfico de linhas:** apresenta a temperatura e a umidade registradas entre 12:00 e 17:00.
* **Gráfico de barras:** apresenta a temperatura média e a umidade média de janeiro a junho.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Chart.js

## 📁 Estrutura do projeto

```text
dashboard-chartjs/
├── index.html
├── style.css
└── script.js
```

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. A dashboard será exibida com os gráficos.

## 📌 Observação

Os dados utilizados atualmente são estáticos e foram fornecidos para a atividade. O projeto pode futuramente ser adaptado para receber dados de uma API.
